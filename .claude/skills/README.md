# Skills

Bu klasördeki skill'ler [calesthio/OpenMontage](https://github.com/calesthio/OpenMontage) reposunun
`.claude/skills` klasöründen (commit `9327439`) kopyalandı. OpenMontage AGPLv3 lisanslıdır; skill'lerin bir kısmı
başka kaynaklardan (ör. remotion-dev) derlenmiştir ve kendi lisans notlarını taşır.

- remotion-best-practices — Remotion kalıpları (animasyon, ses, altyazı, geçişler, fontlar...)
- ffmpeg — video/ses dönüştürme, kırpma, sıkıştırma
- playwright-recording — siteyi gezerek demo videosu kaydetme
- framer-motion — React animasyon prensipleri
- beautiful-mermaid — Mermaid diyagramlarını SVG/PNG'ye render etme
- d3-viz — d3.js ile veri görselleştirme
